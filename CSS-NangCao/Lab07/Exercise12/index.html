Responsive reading

At 481 pixels and above, navigation sits beside the article. The breakpoint follows the lab's explicit 480/481 boundary.

At 480 pixels and below, the navigation and article become one column; the destination list becomes a native select control.

The viewport declaration makes CSS pixels correspond to the device width on mobile browsers.

Choose a destination from the select menu to jump to that section. The same destinations remain available as ordinary links on desktop.

The design preserves one content source and changes only its presentation.

Resize to compare both modes.
