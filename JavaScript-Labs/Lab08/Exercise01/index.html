Exercise 8.1

Enabling/Disabling JavaScript

Đổi cài đặt JavaScript và kiểm tra hai thông báo tương ứng.

Trạng thái JavaScript

You have JavaScript enabled

Thử trên Chrome hoặc Edge

  1. Mở DevTools bằng F12, sau đó nhấn Ctrl+Shift+P.
  2. Chọn Disable JavaScript, giữ DevTools mở và tải lại trang.
  3. Chọn Enable JavaScript và tải lại để so sánh.

Trang kiểm tra trong tài liệu hiện không phân giải được tên miền. Bài này tái hiện hai trạng thái tại chỗ.
