Lab 08

JavaScript 1
Language Foundations

Từ cách nạp mã JavaScript và kiểm tra lỗi trên trình duyệt đến mảng, hàm và đối tượng.

  1. Exercise 8.1 Enabling/Disabling JavaScript Đổi cài đặt JavaScript và kiểm tra hai thông báo tương ứng.
  2. Exercise 8.2 Embedded JavaScript Chạy alert() từ thẻ <script> trong phần <head> của HTML.
  3. Exercise 8.3 External JavaScript Nạp hello.js và in biến đếm trước và sau khi tăng.
  4. Exercise 8.4 Using Noscript Hiện thông báo dự phòng khi trình duyệt tắt JavaScript.
  5. Exercise 8.5 Using the Browser Console Đọc biến, thử lệnh và quan sát thông báo trong DevTools.
  6. Exercise 8.6 Using Built-in JavaScript Objects So sánh String object với chuỗi nguyên thủy, rồi dùng Date và Math.
  7. Exercise 8.7 Arrays Dùng push(), unshift() và vòng lặp để sinh lịch tháng 30 ngày.
  8. Exercise 8.8 JavaScript Functions Dùng tham số và giá trị trả về để sinh năm hộp, rồi kiểm tra phạm vi biến.
  9. Exercise 8.9 Functions as Objects Truyền hàm tính thuế làm đối số và định dạng tổng tiền.
  10. Exercise 8.10 Creating JavaScript Objects Tạo hai đơn hàng bằng hàm khởi tạo và gọi phương thức trên từng đối tượng.
  11. Exercise 8.11 Arrays of Objects Duyệt mảng quốc gia, đọc thuộc tính động và hiển thị cờ từ tài nguyên đề bài.

Đề thực hành và dữ liệu quốc gia theo Fundamentals of Web Development, ấn bản 2, Randy Connolly và Ricardo Hoar. Tài liệu và tệp khởi tạo Lab 08.
