EXERCISE 10.9

GET Requests

Gọi GET bất đồng bộ bằng $.get() và dùng $.each() đưa tên thành phố từ JSON vào danh sách.

Đang chờ yêu cầu.

    GitHub Pages tải bản JSON lấy từ dịch vụ gốc của tài liệu ngày 14/11/2026. Địa chỉ gốc dùng HTTP, còn bản HTTPS của máy chủ trả lỗi chứng chỉ khi kiểm tra.
